4. TEST SUMMARY AND WHAT IT MEANS
---------------------------------
All 27 tests in the complete test suite passed in the latest local Windows
run in 0.20 seconds, using Python 3.9.13 and pytest 8.4.2. No test failures
were reported.

The tests cover these areas:

- Booking: A valid booking is accepted. Overlapping appointments for the
  same provider are rejected. Adjacent appointments and appointments for
  different providers are allowed. Duplicate IDs and invalid intervals
  are handled as expected.
- Cancellation: An active appointment can be cancelled. A cancelled
  appointment no longer blocks its time slot. Missing or repeated
  cancellation requests are handled, and cancelling one appointment does
  not affect another.
- Concurrency: Simultaneous overlapping booking attempts for the same
  provider are protected so that only one succeeds. Simultaneous bookings
  for different providers can both succeed.
- Validation: Missing identifiers, invalid timestamp values, naive
  timestamps, and zero or negative durations are rejected. Invalid
  booking attempts do not modify existing booking data, and timezone-aware
  timestamps are normalized to UTC.

Conclusion:
The local Windows test run confirms that all 27 automated tests passed
for the implemented booking, cancellation, concurrency, and validation
behaviour.
